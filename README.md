🚀 Firebase Todo App

A modern and responsive Todo Application built using HTML, CSS, JavaScript, and Firebase. Users can create an account, securely log in, and manage their personal tasks with cloud storage using Firebase Firestore.

🌐 Live Demo

Visit Todo App

✨ Features

User Authentication — Sign up and log in using Firebase Authentication.
Personal Dashboard — Each user gets their own dashboard.
Add Tasks — Create new todo items.
Delete Tasks — Remove tasks when they are no longer needed.
Update Tasks — Manage existing tasks.
Cloud Storage — Store user tasks in Firebase Firestore.
User-Specific Data — Each user's todos are stored separately.
Task Statistics — Display task counters.
Responsive Design — Modern interface for different screen sizes.
Secure Logout — Sign out of your account.

🛠️ Technologies Used


Technology                                   Purpose

HTML5                                      Application structure
CSS3                                       Styling and responsive design
JavaScript (ES6+)                          Application functionality
Firebase Authentication                    User signup and login
Firebase Firestore                         Cloud database
Firebase Hosting                           Application deployment


🎯 Project Purpose

This project was developed to practice and improve practical JavaScript skills, Firebase Authentication, Firestore database operations, and frontend development.
It demonstrates how a frontend application can connect to Firebase services to provide user authentication and cloud-based data management.
